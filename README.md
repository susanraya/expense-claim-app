# expense claim app

expense claim application where you upload reciept and claim the expenses

Generated by the Quorq AI SDLC platform. Two applications, one repository:

- **`frontend/`** -- the approved app design as a Vite + Svelte 5 app. Every screen
  was reviewed and approved, and runs on seeded sample data.
- **`backend/`** -- a NestJS service in TypeScript. No architecture had been
  approved when this repository was created, so it starts with its health check
  and nothing else.

## Running it

```bash
cd frontend
npm install
npm run dev
npm test          # unit tests (Vitest)
npm run lint       # ESLint
npm run format     # Prettier
```

```bash
cd backend
npm install
npm run dev
npm test
npm run lint
npm run format
```
